API Assignments

Two assignments based on Weekend Planner: an API mashup paper prototype and a working web app for the higher-grade requirement.

01API mashup: paper prototype

This part presents the Weekend Planner idea as a paper prototype. It shows how weather data from Open-Meteo and location data from OpenTripMap could be combined to help users plan their day.

02Working web app: higher-grade assignment

This part is a working version of Weekend Planner using only Open-Meteo. Users select a city and fetch current weather through a real API request. The result appears directly on the website, demonstrating the higher-grade requirement to retrieve data from at least one API and display it on the page.
